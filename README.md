# Minimalistic Portfolio Site

#### **Link:** [gokulram.dev](https://gokulram.dev)

Made with :heart: using [Tailwind](https://tailwindcss.com) and [Spline](https://spline.design)

## Docker Setup

This website can be run in a Docker container for easy deployment.

### Using Docker Compose

1. Build and start the container:
   ```
   npm run docker:up
   ```

2. To stop the container:
   ```
   npm run docker:down
   ```

### Manual Docker Commands

1. Build the Docker image:
   ```
   npm run docker:build
   ```

2. Run the Docker container:
   ```
   npm run docker:run
   ```

3. Visit `http://localhost:8080` in your browser.
